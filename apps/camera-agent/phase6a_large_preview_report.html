1. Why the preview was enlarged

The operator uses the live preview to focus, position the field, and judge illumination. The old panel lived inside the 560px .upload-content column with its own 420px cap, leaving an ~445×333 display area — too small for comfortable focusing on a desktop display. Phase 6A makes the preview the dominant element of the microscope panel, as requested.

Scope note (per spec §D): the larger on-screen view does NOT change the physical field of view, magnification, or the number of nodules captured — it only improves operator visibility. No claim of "more nodules because the preview is bigger" is made.

2. Change made (one presentation change, one structural move)

File: nodiq-x/src/pages/Analysis.jsx — the only file changed.

  1. Microscope panel maxWidth: "420px" → "860px" (the wide-panel cap already used by the dataset picker on this page).
  2. The panel moved from inside .upload-content (centered 560px column) to a full-width sibling of the upload zone (same !uploaded branch, fragment-wrapped). It now spans the card content width up to 860px and shrinks responsively below that.

The preview element itself already had the correct responsive recipe — unchanged: width: 100% + aspect-ratio: 4 / 3 + inner <img> with objectFit: "contain".
